Run an .exe in your browser

x86emu is a small x86-32/x86-64 interpreter in C++, compiled here to WebAssembly. Drop in a Windows PE or a Linux ELF executable and it runs the machine code instruction by instruction — library calls like printf are intercepted and serviced by the emulator. It runs off the main thread, so even a multi-second guest keeps the page responsive.
