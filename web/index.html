Run an .exe in your browser

x86emu is a small x86-32/x86-64 interpreter in C++, compiled here to WebAssembly. Drop in a Windows PE or a Linux ELF executable and it runs the machine code instruction by instruction — library calls like printf are intercepted and serviced by the emulator, so the output lands in the console below.

No files leave your browser: the emulator runs entirely client-side. Guest floating-point arithmetic (x87/SSE) is not emulated yet, and ELF images must be statically linked — see the repository README for the current limits.
